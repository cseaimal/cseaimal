# `01` — PROFILE

I'm **Aimal Khan**, a **Computer Systems Engineering student at UET Peshawar** focused on bridging low-level hardware with high-level software.

My work spans **embedded systems, FPGA-based cryptography, secure IoT, Flutter applications, and web engineering**.

I'm currently an **Undergraduate Researcher at the Secured IoT Devices (SID) Lab**, working on **Post-Quantum Cryptography implementation on FPGA** and exploring secure hardware-software architectures.

Alongside research and engineering, I contribute to technology communities, lead student initiatives, and work on programs that introduce young students to **technology, robotics, AI, and engineering**.
